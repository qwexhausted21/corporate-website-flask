# 🏢 InnoTech - Corporate Website with Database

Корпоративный сайт IT-компании. Это фуллстек-проект (Frontend + Backend), который демонстрирует работу с базами данных, шаблонизаторами и серверной логикой.

## 🔥 Особенности проекта

*   **Backend на Python (Flask):** Сервер обрабатывает запросы пользователей.
*   **База данных SQLite:** Динамический блог. Новости хранятся в БД, а не в HTML-коде.
*   **Панель администратора (упрощенная):** Через специальную форму на сайте можно добавлять новые статьи в блог, и они мгновенно появляются на сайте.
*   **Шаблонизатор Jinja2:** Использование базового шаблона (`base.html`) для переиспользования шапки и подвала на всех страницах.
*   **Локальные изображения:** Возможность кастомизировать дизайн, заменяя картинки в папке `static/img/`.

## 🛠 Технологии
*   **Backend:** Python 3, Flask
*   **Database:** SQLite3
*   **Frontend:** HTML5, CSS3, Jinja2

## 🚀 Как запустить
1. Установите Flask: `pip install Flask`
2. Запустите сервер: `python app.py`
3. Откройте в браузере: `http://127.0.0.1:5000`
